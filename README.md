# EnergyDot

## What is this?

EnergyDot is a toy model of fundamental physics. 
It starts with one simple idea:

> **The universe is made of tiny "energy dots" — nothing else.**

From this one assumption, we try to explain:

- **What is a particle?** 
  → A stable cluster of energy dots (like LEGO bricks).

- **What is light?** 
  → A push wave traveling through the dot network. No photon particle needed.

- **What is gravity?** 
  → The elastic deformation of the dot network around a cluster. 
     Other clusters "fall" into that deformation — that's gravity.

- **Why can nothing go faster than light?** 
  → The push speed in the network has a maximum limit — that's c.

## Why does this matter?

- **No extra dimensions** (unlike string theory).
- **No graviton** (gravity is geometry, not a force particle).
- **Testable predictions** (see `/predictions`).

## Current status

We have derived that the network must have an elastic modulus of:

μ ~ c⁴ / (8πG) ≈ 1.2 × 10³⁴ Pa

And that the dot spacing must be the Planck length:

σ ~ √(ℏG/c³) ≈ 1.6 × 10⁻³⁵ m

We have also checked black hole entropy, Hawking temperature, 
and gravitational wave speed — all match observations so far.
