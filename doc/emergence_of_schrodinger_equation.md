# 薛定谔方程的涌现：从能量子网络到量子力学

## 概述

在 EnergyDot 模型中，宇宙的基本实体是离散的、做零點振動的能量子。物质粒子（电子、质子等）是能量子的稳定团簇。量子力学的核心方程——薛定谔方程——应当是这些团簇在能量子网络中集体运动的**有效描述**，而非基本公理。

本文档提出一条从网络微观规则到薛定谔方程的涌现路径，并列出需要严格数学验证的步骤。

---

## 1. 基本假设回顾

- **能量子网络**：充满全空间，平均间距 σ，每个能量子在平衡位置附近做零點振動，频率 ν₀ ~ c/σ。
- **推挤传递**：能量子之间通过接触性推挤传递动量，传播极限速度为光速 c。
- **物质团簇**：由 N 个能量子组成的稳定束縛态，总质量 m = N ε₀ / c²，其中 ε₀ 是单能量子能量。
- **普朗克常数**：h = 2π ε₀ σ / c，是最小作用量单位（详见 `derivation_of_planck_constant.md`）。

## 2. 波函数作为集体激发的振幅

当团簇在能量子网络中移动时，它会扰动周围的能量子，产生一个**伴随的位移场**或**密度波**。这个集体激发可以用一个复振幅 ψ(x, t) 来描述，其模平方 |ψ|² 正比于在位置 x 处发现团簇的概率密度（网络状态的概率分布）。

在离散网络上，ψ 定义在格点上，满足某种主方程（master equation）。

## 3. 从离散随机过程到薛定谔方程

标准数学物理中，连续空间上的薛定谔方程可以从以下两种路径涌现：

### 3.1 路径积分方法 (Feynman-Kac 公式)

对于一个在势场 V(x) 中运动的粒子，其演化算符可以写成路径积分：
\[
\psi(x,t) = \int K(x,t; x_0,0) \psi(x_0,0) dx_0
\]
核函数 K 可以表示为作用量指数的积分。在 EnergyDot 网络中，每一步“推挤”对应一个微小的转移概率，当网络间距 σ → 0 并适当重整化后，可以证明 K 趋近于自由粒子的传播子，加上势项。

**需要验证**：从能量子之间的推挤跃迁概率（例如依赖于邻居相对位移的某种形式），能否推导出路径积分的相位因子 exp(iS/ħ)？

### 3.2 离散 Schrödinger 方程 (格点模型)

在立方格点上，自由粒子的离散薛定谔方程为：
\[
i\hbar \frac{\partial \psi_n}{\partial t} = -J \sum_{\langle m,n \rangle} (\psi_m - \psi_n)
\]
其中 J 是跃迁振幅，与 ħ、格距 a 和粒子质量有关。在连续极限 a → 0 下，上式恢复为连续薛定谔方程，且 J = ħ²/(2ma²)。

在 EnergyDot 网络中：
- 格距 a = σ（能量子间距）。
- 跃迁振幅 J 应来自能量子之间的推挤速率和质量团簇的惯性。
- 需要验证：从微观推挤动力学计算 J，是否满足 J ∝ ħ²/(2mσ²)？

## 4. 具体推导计划

### 4.1 建立离散概率主方程

设 P_n(t) 为团簇位于格点 n 的概率。由于能量子的随机推挤，团簇可以以一定速率 Γ 跃迁到近邻格点。主方程：
\[
\frac{dP_n}{dt} = \Gamma \sum_{\langle m,n \rangle} (P_m - P_n)
\]
这是经典随机游走。要得到量子力学，需要引入相位。在 EnergyDot 网络中，团簇的运动不仅改变位置，还会累积来自背景零點振动的相位因子。原因：零點振动周期极短，团簇在每次跃迁时会“感受到”一个与跃迁方向有关的相位差，类似于 Aharonov-Bohm 效应。

如果我们假设跃迁振幅是复数，并设 ψ_n = √P_n e^{iθ_n}，那么主方程可以推广为复系数方程。当跃迁的相位差正比于跃迁方向上的某种势场时，可以得到带外势的离散薛定谔方程。

### 4.2 从推挤动力学导出跃迁振幅

考虑一个团簇位于格点 n，其周围的能量子不断推挤它。由于网络各向同性，左右推挤的净效果为零。但量子力学中的“动能”项来自于二阶跃迁过程：团簇可以通过虚中间态跃迁到近邻，有效振幅 J 正比于 (推挤强度)² / (能量子振动能级差)。

粗略估计：每次推挤的能量交换 ∼ ε₀，时间间隔 ∼ σ/c，因此等效的“相互作用强度” ∼ ε₀。经过二阶微扰，跃迁振幅 J ∼ (ε₀)² / (ħ ν₀) = (ε₀)² / (ħ c/σ) = ε₀² σ / (ħ c)。代入 ε₀ = ħ c / σ（从 ε₀ / ν₀ = ħ 及 ν₀ = c/σ 得 ε₀ = ħ c/σ），则 J ∼ (ħ² c²/σ²) * σ / (ħ c) = ħ c / σ。另一方面，我们希望 J = ħ²/(2m σ²) 且 m = N ε₀/c² = N ħ c/(σ c²) = N ħ/(σ c)，代入得 J = ħ² / (2 (N ħ/(σ c)) σ²) = (ħ² * σ c) / (2 N ħ σ²) = (ħ c) / (2 N σ)。所以 J 中会出现 1/N 因子，而我们的简单估计没有 N。这说明跃迁振幅与团簇大小（质量）有关，这是合理的：团簇越大越难跃迁。需要更精确的模型。

### 4.3 连续极限

当 σ → 0，N → ∞ 但保持 m 有限时，通过泰勒展开离散薛定谔方程就得到连续版本。这里需要验证：有效质量 m 与微参数 N、σ 的关系为 m = N ε₀/c²，而 ħ = ε₀ σ / c，因此 ħ²/(2m) = (ε₀² σ²/c²) / (2 N ε₀/c²) = (ε₀ σ²) / (2N) = (ħ c/σ * σ²) / (2N) = ħ c σ / (2N)。而连续化后的系数必须等于经典扩散系数与 ħ 的组合。这一部分需要仔细的尺度分析。

## 5. 需要数学家/物理学家验证的关键点

1. **跃迁振幅 J 的微观推导**：从能量子推挤的随机过程，能否严格导出复数跃迁振幅，并得到 J = ħ²/(2mσ²)？
2. **相位的起源**：零點振动的相位累积如何导致薛定谔方程中的虚数单位 i？
3. **连续极限的有效性**：在何种条件下（长波、低频）离散方程收敛到连续薛定谔方程？
4. **势能的嵌入**：外部势场 V(x)（例如电磁势或引力势）如何从网络的不均匀性（例如能量子密度变化）中涌现？
5. **非线性修正**：薛定谔方程是线性的，但在 EnergyDot 网络中，高密度团簇可能会改变网络本身，导致非线性项（类似于 Gross-Pitaevskii 方程）。这是否可观测？

## 6. 结语

本文件并未完成严格推导，而是提出一个可行的研究纲领。我们认为，薛定谔方程是能量子网络在特定极限下的**涌现现象**，而非基本假设。这一视角可能为量子力学的基础问题（如测量问题、波函数塌缩）提供新的解决思路。

我们诚邀数学家和物理学家参与验证上述推导，或提供替代的涌现机制。
