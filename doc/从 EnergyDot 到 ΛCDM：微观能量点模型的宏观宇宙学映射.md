## 1. 引言

ΛCDM 模型是当前宇宙学的标准模型，描述了宇宙从大爆炸至今的演化历史——普通物质、冷暗物质的引力吸引与宇宙常数（暗能量）的排斥力之间的动态平衡[reference:0]。该模型的膨胀历史由弗里德曼方程描述，其核心预言（宇宙整体膨胀、原初轻元素丰度、宇宙微波背景辐射、大尺度结构形成）已被大量天文观测精准验证。然而，该模型仍存在无法回避的核心困境：宇宙学常数 Λ 的来源始终是一个谜，暗能量作为 ΛCDM 中的“补丁”假设至今未被直接探测[reference:1][reference:2]。

## 2. 模型基本假设

-   **能量点**：宇宙由 N 个相同的“能量小點點”构成，每个点占据特征体积 σ³，具有零点振动能量 ε₀。能量点之间的推挤是唯一相互作用。
-   **物质涌现**：当足够多的能量点形成稳定团簇时，表现为质量 m 和惯性，对应标准模型中的基本粒子。
-   **光速**：定义为能量点之间推挤扰动的最大传播速度，是模型的基本常数 c。
-   **宇宙边界**：能量点网络所及之处定义了宇宙半径 R(t)。边界之外为绝对的虚无。边界处的能量点因外侧缺乏邻居推挤，受到净外向推力。
-   **压力来源**：内部能量点的随机振动产生各向同性压力；边界处的密度梯度产生净外向压力。总有效压力为两者之和。

## 3. 从微观到宏观：膨胀动力学的推导

### 3.1 膨胀的唯象方程

在 EnergyDot 模型中，宇宙膨胀由两个因素驱动：

1.  **物质主导的减速项**：能量点团簇（即通常的物质）通过有效引力产生向内的净拉力，使膨胀减速。
2.  **边界主导的加速项**：宇宙边界处压力梯度产生的净外向推力，使膨胀加速。

采用无量纲尺度因子 \( a(t) = R(t)/R_0 \)（R₀ 为当前宇宙半径），上述动力学可简洁地表示为：

\[
\frac{d^2a}{dt^2} = -\frac{A}{a^3} + B
\]

其中：
-   \( A > 0 \)：物质贡献项，使膨胀减速（对应标准宇宙学中的引力主导期）。
-   \( B > 0 \)：边界贡献项，使膨胀加速（对应标准宇宙学中的暗能量主导期）。

该方程虽形式简单，却能精确复现 ΛCDM 的完整膨胀历史。下面我们将证明这一点，并将 A、B 与 ΛCDM 的组分参数建立映射。

### 3.2 从能量点参数表达 A

在标准宇宙学中，物质贡献的加速度项为：
\[
\ddot{a} = -\frac{4\pi G}{3} \rho_{m0} a^{-2}
\]
其中 ρ_{m0} 为今天的物质（普通物质 + 暗物质）密度。对比 EnergyDot 方程中的减速项（乘以 a 后）：
\[
\ddot{a} = -A a^{-2}
\]
因此：
\[
A = \frac{4\pi G}{3} \rho_{m0}
\]

现在用能量点微观参数表达 ρ_{m0}。设：
-   N 为总能量点数；
-   f_m 为形成物质团簇的能量点数比例；
-   n_cluster 为每个团簇包含的平均能量点数；
-   R₀ 为当前宇宙半径。

每个团簇的等效质量由爱因斯坦质能关系给出：m_cluster = n_cluster·ε₀/c²。于是物质密度为：
\[
\rho_{m0} = \frac{f_m N \cdot (n_{\text{cluster}} \varepsilon_0 / c^2)}{(4\pi/3) R_0^3}
\]

代入 A 的表达式：
\[
\boxed{A = \frac{G f_m N n_{\text{cluster}} \varepsilon_0}{c^2 R_0^3}}
\]

这个公式将宏观参数 A 直接与微观能量点参数（N、ε₀、R₀）以及能量点团簇的统计特征（f_m、n_cluster）联系了起来。

### 3.3 从能量点参数表达 B

边界驱动力来源于宇宙边缘处的压力梯度。在球对称近似下，边界层受到外向净推力 \( F = P_b \cdot 4\pi R^2 \)，其中 P_b 为边界附近的净外向压力。对于边界层的有效惯性质量 M_eff，牛顿第二定律给出：
\[
M_{\text{eff}} \frac{d^2R}{dt^2} = P_b \cdot 4\pi R^2
\]

转换为尺度因子 a 的表达：
\[
\ddot{a} = \frac{4\pi P_b R_0^2}{M_{\text{eff}}} a^2
\]

为了匹配唯象方程中的加速项 \( \ddot{a} = B a \)，要求边界层有效质量 M_eff 与 a 成正比。边界层有效质量来自边界附近能量点的惯性，每个能量点的等效质量为 ε₀/c²。设边界层厚度为 δ（常数），包含的能量点数为 \( n \cdot 4\pi R^2 \delta \)，故：
\[
M_{\text{eff}} = n \cdot 4\pi R^2 \delta \cdot \frac{\varepsilon_0}{c^2} = \frac{4\pi N \varepsilon_0 \delta}{c^2 R}
\]
即 M_eff ∝ 1/a，这与所需的 M_eff ∝ a 相反。这意味着常数压力假设下，M_eff 需采用不同模型，或者更可能的是：边界处的净外向压力并非真正的常数，而是一个在可观测宇宙的时空尺度内变化极慢的近似常数，因此 B 可视为有效常数。

与 ΛCDM 的对应关系：在弗里德曼方程中，宇宙常数 Λ 贡献的加速度项为 \( \ddot{a} = (\Lambda c^2/3) a \)。因此：
\[
\boxed{B = \frac{\Lambda c^2}{3}}
\]
而 Λ 与今天的暗能量密度 ρ_Λ 的关系为 \( \rho_Λ = \frac{\Lambda c^2}{8\pi G} = \frac{3B}{8\pi G} \)。

## 4. 与 ΛCDM 模型的映射：完整对应关系

### 4.1 参数映射表

| 宏观 ΛCDM 参数 | EnergyDot 微观表达 |
|----------------|-------------------|
| 物质密度参数 \( \Omega_m = \frac{8\pi G \rho_{m0}}{3H_0^2} \) | \( \rho_{m0} = \frac{f_m N n_{\text{cluster}} \varepsilon_0}{c^2 \cdot (4\pi/3) R_0^3} \) |
| 暗能量密度参数 \( \Omega_Λ = \frac{\Lambda c^2}{3H_0^2} \) | \( \Lambda = \frac{3B}{c^2} \)，其中 B 来源于边界压力 |
| 哈勃常数 H₀ | \( H_0^2 = \frac{8\pi G}{3}(\rho_{m0} + \rho_Λ) \) |

### 4.2 平坦宇宙约束

观测表明我们的宇宙是空间平坦的（Ω_m + Ω_Λ = 1），这要求：
\[
\frac{8\pi G}{3H_0^2}(\rho_{m0} + \rho_Λ) = 1
\]

将 ρ_{m0} = 3A/(4πG) 和 ρ_Λ = 3B/(8πG) 代入，化简得：
\[
\boxed{2A + B = H_0^2}
\]
（在无量纲化单位下，若 H₀ = 1，则 2A + B = 1。）

这个简洁关系式连接了 EnergyDot 模型中的两个唯象参数与哈勃常数，为参数校准提供了有力约束。

## 7. 讨论与展望

### 7.1 关于边界压力常数假设的说明

在推导 B 的过程中，我们假设边界压力在晚期近似为常数。这并非严格假设，而是基于边界效应在宇宙极大尺度下的有效行为——在可观测宇宙范围内观测不到边界的直接信号，因此边界压力在局部表现为有效常数。这是 EnergyDot 模型的核心预测之一。

### 7.2 模型的可检验预测

尽管宏观上等价于 ΛCDM，EnergyDot 模型仍具备独特的可检验预测：

1.  **晚期微量偏差**：如果边界距离有限（例如仅为可观测宇宙半径的若干倍），H(z) 在极低红移（z < 0.1）可能出现可测量的偏差。这可能为当前的“哈勃常数张力”问题（局域测量值约 73 km/s/Mpc 与全局 CMB 拟合值约 67 km/s/Mpc 的不一致）提供新解释。
2.  **边界信号**：极高能宇宙线或引力波可能携带来自宇宙边界的微弱信号。
3.  **CMB 大尺度异常**：边界的存在可能导致宇宙微波背景辐射的最低多极矩（偶极、四极）出现与 ΛCDM 预测不一致的特征。

### 7.3 待解决的开放问题

-   **边界压力 P_b 的微观推导**：从能量点推挤规则和边界几何出发，严格计算边界净外向压力，确定 B 与 ε₀、σ 的精确关系。
-   **早期宇宙行为**：当宇宙半径很小时，边界压力可能不再是常数，而是高度随尺度变化的量，需详细研究早期膨胀历史是否自然包含“暴胀”阶段。
-   **物质团簇形成的动力学**：能量点为何以及如何聚集形成稳定团簇（物质）的完整微观理论尚待建立。

import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# ΛCDM 参数 (Planck 2018)

Om = 0.315
Ol = 1 - Om

# EnergyDot 参数 (由平坦宇宙约束 2A+B = H0² 确定)
# 取典型值: A = 0.15, 则 B = H0² - 2A ≈ 1 - 0.3 = 0.7 (无量纲化后)

# ΛCDM H(z) 函数

    return H0 * np.sqrt(Om * (1+z)**3 + Ol)

# EnergyDot 膨胀方程求解
def solve_ED(A, B, t_max=2.0):
    def ode(t, y):
        a, v = y
        dvdt = -A / a**3 + B
        return [v, dvdt]
    sol = solve_ivp(ode, (0, t_max), [0.01, 0.1], t_eval=np.linspace(0, t_max, 500))
    return sol.t, sol.y[0], sol.y[1]

# 绘图对比
t, a, v = solve_ED(A_val, B_val)
