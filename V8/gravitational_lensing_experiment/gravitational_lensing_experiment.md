# 引力透鏡實驗紀錄：V8.4.0 宇宙引擎演化報告

本文件紀錄了在基於 `WaveStringUniverseSim3D` (V8.4.0) 的宇宙引擎中，針對引力透鏡效應的湧現現象所進行的模擬實驗進度與物理驗證。

## 1. 實驗目標
驗證在連續介質力學框架下，透過局部調整空間剛度 (Alpha/Gamma) 是否能湧現出符合廣義相對論預測的引力透鏡現象（光線偏折）。

## 2. 模擬參數設定
- **引擎版本**：V8.4.0 (算子對齊與哈密頓守恆版)
- **網格尺寸**：64x64x64
- **引力井定義**：於中心點建立高斯勢能分布，參數 `Rs=8.0`，偏折係數 `epsilon=0.7`。
- **光束參數**：高斯波包 (Sigma=2.5)，振幅調整為 0.1 以防止數值崩塌。

## 3. 關鍵觀測結果
實驗成功捕捉到光波穿過引力井邊緣時的偏折現象。下表對比了平直時空與透鏡時空的測量數據：

| 指標 | 數值 |
| :--- | :--- |
| 平直時空終點 Y 座標 | 37.247 |
| 透鏡效應終點 Y 座標 | 32.515 |
| **總偏折量 (Delta Y)** | **-4.732 格** |

## 5. 物理現象分析
1. **測地線偏折 (Geodesic Deflection)**：紅線軌跡證實光波在進入引力井勢能場後，路徑產生了明顯的向心偏折，符合廣義相對論預測。
2. **數值色散損耗 (Numerical Dispersion)**：波包在傳播過程中出現了能量擴散，這是因為離散網格對波的限制效應。
3. **測量誤差 (Observer Effect)**：在 Step 3000 後出現的「回跑」現象，經分析是由於質心演算法誤將後方的能量拖尾（Wave Wake）納入計算所致。
